# LEDs em Paralelo
Projeto 3 — Montagem prática com componentes em paralelo, desenvolvido no Tinkercad.

## Objetivo
Conectar múltiplos LEDs usando uma única fonte de alimentação, compreender a função do resistor e como a corrente se divide em caminhos paralelos.

## Montagem
- Fonte: Bateria CR2032 (3,0 V)
- 3 LEDs de cores diferentes
- 3 resistores limitadores de corrente
- Multímetro para verificação de tensão

## Resultado
- Tensão medida: 2,80 V (queda normal devido aos componentes)
- Todos os 3 LEDs acenderam com brilho uniforme ✅

## Conceito compreendido
Em paralelo, todos os componentes recebem a mesma tensão. Cada LED tem seu próprio caminho e seu próprio resistor — se um sair, os outros continuam funcionando.
